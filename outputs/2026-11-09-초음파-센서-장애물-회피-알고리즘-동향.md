# 초음파 센서 기반 장애물 회피 알고리즘 동향 — 3회차 (2026-11-09)

## 핵심 요약 (3줄)
1. 과거 2회차까지 미해결이던 "초음파+인공잠재장(APF) 직접결합 연구 공백"은 비peer-review 취미 프로젝트(os.mbed.com, 날짜·신뢰도 불명)에서만 부분적 사례가 확인되었을 뿐, **학술적으로 검증된 직접결합 연구는 여전히 공백**이다.
2. 이번 회차 신규 조사 대상(arXiv 2504.11064, GitHub uu-isrc-robotics) 모두 초음파가 아닌 다른 센서(MATLAB 시뮬레이션/라이다) 기반으로 재확인되어, "초음파+APF" 공백을 메우지 못했다.
3. DOI 혼동(이전 회차가 찾던 `978-981-95-8981-4_15`는 여전히 확인불가, 대신 서보+초음파 휠체어 논문 `978-3-032-12999-4_50`이 발견·교차확인됨)과 WebFetch 도메인 차단(arxiv.org, doi.org 등)으로 인해 이번 회차는 2차 소스 의존도가 높았으며, 다음 회차에서 네트워크 접근 확보 후 재검증이 필요하다.

## 0. 이전 회차 핵심 결론 요약 (맥락용, 상세는 과거 보고서 참조)
- HC-SR04 다중센서 crosstalk 지연은 **60ms**가 1차 출처 기준 확정(33ms/100ms는 미확인·저신뢰).
- arXiv 2603.13907 "LineMaster Pro"는 논문공장(AI-slop) 의심이 2회 연속 강화됨 — 성능 수치 인용 금지, 단 공식 철회/조사는 없어 단정 서술도 금지.
- arXiv 2312.04072의 "23.97ms" 지연 수치는 2회 연속 근거 미발견 — 인용 금지.
- 검증된 선행연구로 Saranga(arXiv 2603.24699, Science Robotics)와 BatDeck(arXiv 2412.10048)이 확인됨 (파생 수치 일부는 부분검증).
- GitHub `Mingrui-Yu/RaspberryCar`는 2020-05-24 최종 커밋으로 비활성 확정.
- ROS2 Nav2 통합(LaserScan 변환, 2D ObstacleLayer)은 실무정보로 확인됨(정량 벤치마크는 미확인).
- 초음파+APF 직접결합 연구 공백이 2회차까지 미해결 → 3회차 최우선 조사 과제로 설정됨.

## 1. (최우선 과제) 초음파+APF 직접결합 연구 공백 — 부분적 해소, 그러나 학술적 공백은 유지

이번 회차의 핵심 조사 목표였던 "초음파 센서와 인공잠재장(APF)을 직접 결합한 연구"에 대해 세 건을 교차검증했다.

| 자료 | 내용 | 판정 | 비고 |
|---|---|---|---|
| arXiv 2504.11064 "DSA-AAPF" (MDPI *Drones* 9(6):390, DOI 10.3390/drones9060390) | 다중 UAV 포메이션 장애물회피, 개선 시뮬레이티드어닐링+적응형APF | **부분확인** | 2025-04-15 제출(2026년 신규 자료 아님, 날짜 혼동 주의). MATLAB 시뮬레이션 기반이며 ultrasonic/sonar 키워드 결합검색에서 매칭 없음 → **초음파 비결합**으로 재확인 |
| GitHub `uu-isrc-robotics/potential_fields_based_obstacle_avoidance` | APF 기반 장애물회피 오픈소스 | **확인됨(반증)** | 소스코드 직접 열람 — LaserScan(라이다) 기반이며 sonar 처리 코드 없음(docstring에 "laser and/or sonar" 언급만 있고 실제 구현 없음) → **초음파 비결합** |
| os.mbed.com "Potential Field Robot" (Cyntal, mbed NXP LPC1768) | HC-SR04 sonar 2개의 측정값을 모터 속도벡터의 virtual force로 직접 변환 | **확인됨(내용)/확인불가(날짜)**, 신뢰도 낮음 | 초음파+APF 직접결합 사례로 내용은 확인되나, 비peer-review 개인 취미 프로젝트이며 구형 플랫폼으로 보아 2010년대 추정(**미확인/추정**). mbed.org 저장소는 2026-07 영구삭제 예정 공지가 있어 향후 접근 불가 위험 있음 |

**종합 판단**: os.mbed.com 사례로 "초음파와 APF를 직접 결합한 구현이 존재한다"는 사실 자체는 확인되었으나, 이는 학술 검증(peer review)을 거치지 않은 구형 취미 프로젝트 1건에 불과하다. 반면 이번 회차에 새로 조사한 두 학술/오픈소스 자료(UAV APF, 라이다 APF)는 모두 초음파 비결합으로 재확인되었다. 따라서 **"초음파+APF를 직접 결합한, 학술적으로 검증된 연구"는 3회차 종료 시점까지도 공백 상태**라고 명시한다. 이는 과거 2회차까지의 공백 판정을 완전히 해소한 것이 아니라 "실무/취미 수준의 결합 사례는 존재하나 학술적 검증 사례는 없음"으로 한 단계 구체화된 것이다.

## 2. 신규 발견: 서보 회전식 단일 초음파 센서 다방향 스캔 (휠체어 장애물회피 논문)

- **DOI 10.1007/978-3-032-12999-4_50** (Jongchanachavawat 외, Springer *Smart Innovation, Systems and Technologies* vol.468, pp.569-579, 2026년 출판)
- **확인됨**: KMITL dspace와 SWU 기관레포지토리 2곳에서 독립 교차확인 — 제목, venue(SIST vol.468, pp.569-579), 성공률 수치 모두 일치.
  - 서보모터에 초음파 센서 1개를 장착해 30°/60°/120°/150° 방향으로 스캔
  - 성공률: 정면 100%, 전면-좌측 80%, 3면 장애물 상황 60%
  - APF는 사용하지 않은 **단순 규칙기반(rule-based)** 알고리즘
  - 실패 원인: 2cm 이내 근접 물체 미감지
  - 발행 월/일은 **확인불가**(연도만 확인)
- **DOI 혼동 이슈**: 과거 회차(2회차까지)가 찾고 있던 `978-981-95-8981-4_15`는 이번 회차에도 **확인불가**(doi.org 접근 차단, 다각도 검색에도 매칭 없음, 오기/가짜 DOI 가능성도 배제 못함). 위 `978-3-032-12999-4_50`이 그 논문의 오기였을 가능성이 제기되었으나 **확정되지 않음** — 다음 회차 doi.org 접근 확보 후 재확인 필요.
- **실무 적용 관점(추정 아닌 평가)**: 서보 회전식 단일 초음파 센서로 다방향 스캔하는 방식은 다중 센서 대비 저비용 구현이 가능해 라즈베리파이/RC카 등 실무 적용에 참고 가치가 있다고 판단된다. 단 2cm 이내 근접 물체 미감지라는 한계는 실제 적용 시 고려 필요.

## 5. 이번 회차 환경 제약 및 한계 (명시)

이번 세션에서는 WebFetch가 **github.com을 제외한 거의 모든 외부 도메인에서 DNS 차단**되었다(arxiv.org, doi.org, link.springer.com, mdpi.com, os.mbed.com 등). 이로 인해 다음 항목들은 **원문 직접대조 없이 WebSearch 스니펫(2차 정보) 기반으로만 판정**되었으며, 신뢰도가 1차 출처 직접열람 대비 낮다:

- arXiv 2504.11064의 ultrasonic 비언급 판정 (부분확인)
- os.mbed.com 사례의 날짜 (확인불가)
- DOI `978-3-032-12999-4_50`의 발행 월/일 (확인불가)

반면 GitHub 저장소 2건(`uu-isrc-robotics`, `DRL-robot-navigation-IR-SIM`)은 github.com 접근이 가능해 **소스코드/README 직접열람으로 확인**되었다.

## 6. 다음 회차 액션 아이템

1. `arxiv.org`, `doi.org`, `link.springer.com`, `mdpi.com`, `os.mbed.com`, `dspace.kmitl.ac.th` 등 도메인 네트워크 접근 허용 필요 — 이번 회차 DNS 차단으로 원문 직접검증이 제한적이었음.
2. DOI `978-981-95-8981-4_15` vs `978-3-032-12999-4_50` 혼동 이슈를 doi.org 직접 조회로 확정.
3. os.mbed.com "Potential Field Robot" 프로젝트의 게시 날짜 확인(단, mbed.org 저장소 2026-07 영구삭제 예정 공지로 인해 접근 불가 위험 있음 — 가능하면 이번 회차 내 아카이브 확보 권장).
4. 학술적으로 검증된 "초음파+APF 직접결합" 연구가 여전히 발견되지 않는다면, 4회차 이후 탐색 범위를 다른 유사 기법(예: 초음파+VFH, 초음파+DWA)으로 확장할지 판단 필요.
