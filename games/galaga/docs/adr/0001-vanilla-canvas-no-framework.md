# ADR-0001: 게임 엔진·프레임워크 없이 순수 Canvas 2D 사용

날짜: 2026-09-16
상태: 채택

## 맥락

간단한 고정 화면 슈팅 게임을 브라우저에서 바로 실행 가능하게 만들어야 한다(NFR-1: 런타임 외부 의존성 없음, 단일 HTML 산출물).
Phaser, PixiJS 같은 엔진은 스프라이트·물리·씬 관리를 제공하지만 번들 크기가 수백 KB이고, 단일 파일 배포 시 인라인해야 한다.

## 결정

Canvas 2D API만 사용하고 게임 루프, 엔티티, 충돌 판정을 직접 구현한다.
개발 도구(Vite, TypeScript, Vitest, Playwright)는 devDependency로 사용하되 런타임에는 아무것도 포함하지 않는다.

## 결과

- 장점: 산출물이 수십 KB, 외부 네트워크 요청 없음, 로직이 단순해 단위 테스트가 쉽다.
- 단점: 스프라이트 애니메이션·씬 전환 같은 기능을 필요할 때 직접 만들어야 한다. 범위(FR 목록)가 고정되어 있으므로 수용 가능하다.
- 렌더링과 규칙을 분리(ADR-0002)해 나중에 엔진으로 교체할 여지를 남긴다.
