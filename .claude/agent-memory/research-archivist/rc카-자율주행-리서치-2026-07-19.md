**주제**: 라즈베리파이 기반 RC카 자율주행 최신 동향 (2026-07-19 리서치, 목적: 서브에이전트 파이프라인 web-researcher → source-verifier → report-writer 동작 테스트)
**보고서**: outputs/2026-07-19-라즈베리파이-RC카-자율주행-동향.md

핵심 발견:
1. Donkeycar가 라즈베리파이 자율주행 RC카 분야의 사실상 표준 오픈소스 프레임워크 (최신 버전 5.1, RPi 4/5 + Bookworm 64비트 요구).
2. Raspberry Pi 5는 RP1 사우스브릿지 칩 때문에 기존 RPi.GPIO 라이브러리가 작동하지 않음 — gpiozero(공식 권장) 또는 rpi-lgpio(드롭인 대체)로 마이그레이션 필요. 다중 소스로 교차 확인됨.
3. "Flutter 앱 + WebSocket + 라즈베리파이 RC카 모터 제어"를 동시에 만족하는 공개 레퍼런스 사례는 검색 범위 내에서 발견되지 않음 (유사 사례들은 HTTP/Flask, D-Bus, React 등으로 프로토콜/프레임워크가 다름).

**후속 갱신 (2026-08-17, ★재확인 불필요):** 2번 항목과 관련해, 당시 gpiozero의 Pi5 lgpio 핀 팩토리 버그(Issue #1166, 2024-08-21 제보)는 이 리서치 시점(2026-07-19)에도 미해결 상태였음. 이후 [[pwm-gpio-모터제어-리서치-2026-08-17]]에서 확인한 바, **2026-07-25에 이슈 종료 및 gpiozero 2.0.1.post1(최종 post3, 2026-07-27) 배포로 공식 수정**됨. 즉 이 문서의 "gpiozero/rpi-lgpio로 마이그레이션 필요"라는 권고는 여전히 유효하나, "Pi5 GPIO 핀 팩토리 버그가 아직 안 고쳐졌는지"는 더 이상 재조사할 필요 없이 "2026-07-25/27자로 해결됨"으로 답하면 됨.

**Why:** 줄리앙의 RC카 프로젝트(Flutter 앱 + WebSocket 통신 + Raspberry Pi + OpenCV 자율주행)와 직접 관련된 기술 스택을 조사한 결과.
**How to apply:** 줄리앙이 (a) 하드웨어를 Raspberry Pi 5로 업그레이드하거나, (b) GPIO 제어 코드를 작성/수정하거나, (c) 자율주행 프레임워크 채택 여부를 논의할 때 이 발견을 먼저 참고. 특히 Pi 5로 전환 시 GPIO 라이브러리 비호환 이슈를 사전에 반드시 고지할 것(단, 2026-08-17 기준 gpiozero>=2.0.1.post3이면 Issue #1166 문제는 해결된 상태임을 함께 안내). Flutter+WebSocket 조합은 참고할 기존 공개 사례가 부족하므로 직접 설계가 필요하다는 점을 안내할 것.
