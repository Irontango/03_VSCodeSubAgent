**보고서**: outputs/2026-07-19-라즈베리파이-RC카-자율주행-동향.md

핵심 발견:
1. Donkeycar가 라즈베리파이 자율주행 RC카 분야의 사실상 표준 오픈소스 프레임워크 (최신 버전 5.1, RPi 4/5 + Bookworm 64비트 요구).
2. Raspberry Pi 5는 RP1 사우스브릿지 칩 때문에 기존 RPi.GPIO 라이브러리가 작동하지 않음 — gpiozero(공식 권장) 또는 rpi-lgpio(드롭인 대체)로 마이그레이션 필요. 다중 소스로 교차 확인됨.
3. "Flutter 앱 + WebSocket + 라즈베리파이 RC카 모터 제어"를 동시에 만족하는 공개 레퍼런스 사례는 검색 범위 내에서 발견되지 않음 (유사 사례들은 HTTP/Flask, D-Bus, React 등으로 프로토콜/프레임워크가 다름).

**Why:** 줄리앙의 RC카 프로젝트(Flutter 앱 + WebSocket 통신 + Raspberry Pi + OpenCV 자율주행)와 직접 관련된 기술 스택을 조사한 결과.
**How to apply:** 줄리앙이 (a) 하드웨어를 Raspberry Pi 5로 업그레이드하거나, (b) GPIO 제어 코드를 작성/수정하거나, (c) 자율주행 프레임워크 채택 여부를 논의할 때 이 발견을 먼저 참고. 특히 Pi 5로 전환 시 GPIO 라이브러리 비호환 이슈를 사전에 반드시 고지할 것. Flutter+WebSocket 조합은 참고할 기존 공개 사례가 부족하므로 직접 설계가 필요하다는 점을 안내할 것.
