**주제**: 초음파 센서 기반 장애물 회피 알고리즘 동향 (2026-09-14 격주 후속 리서치)
**보고서**: outputs/2026-09-14-초음파-센서-장애물-회피-알고리즘-동향.md
**이전 회차**: [[초음파-센서-장애물회피-리서치-2026-07-20]]

**이전 리서치와의 관계:** [[초음파-센서-장애물회피-리서치-2026-07-20]]에서 제기된 미해결 항목(LineMaster Pro 저자 소속 이례성, HC-SR04 crosstalk 지연시간 60ms vs 33ms 상충 여부, 초음파+APF 결합 연구 공백, arXiv 2312.04072 "23.97ms" 수치)을 재확인하기 위한 격주 후속 조사. 신규로 항공로봇 분야 초음파 센싱 연구 2건을 추가 발견함.

핵심 발견:
1. **신규 검증됨 — 항공로봇 초음파 센싱 연구 2건**
   - **Saranga** (arXiv 2603.24699, Science Robotics DOI 10.1126/scirobotics.adz9609, WPI+TDK InvenSense, 2026-03): 팜사이즈 항공로봇용 저전력(1.2mW) 듀얼 소나 어레이. -4.9dB의 낮은 SNR을 물리적 차폐+UNet 디노이징으로 극복. arXiv·WPI ETD·PubMed(41880528) 3개 출처에서 수치 일치. 단 "70%+" 인식/회피 성공률 표현은 원문상 조건별 72~100% 범위의 단순화이므로 재인용 시 주의(부분 검증).
   - **BatDeck** (arXiv 2412.10048, 2024-12-13, Crazyflie 2.1 확장보드, TDK ICU-x0201): ego-velocity 추정 MSE 0.019 m/s, 8분 비행 시 평균 136m 이동. arXiv·ResearchGate 수치 일치. "17배/50% 향상" 수치는 원문 표 재대조 미완료(부분 검증).
2. **HC-SR04 crosstalk 지연시간 판정 갱신**: 60ms(SparkFun/HandsOnTec/Digi-Key 게재 공식 데이터시트, 단일센서 측정주기 기준)는 계속 검증됨·1차 신뢰로 우선 채택. 33ms(Industrial Monitor Direct 블로그, 순차발사 최소간격 이론계산치)는 2026-07-20에는 "인용 금지"였으나, 이번에 60ms와 산출 목적이 다른 별도 수치임이 명확해져 **"부분 검증/저신뢰로 인용 가능하나 60ms 우선"으로 완화**됨. 100ms(밀폐공간 반향 대응 목적 언급)는 1차 출처 미발견으로 확인불가 유지.
3. **arXiv 2603.13907 "LineMaster Pro" 의심 정황 강화**: 저자 소속 무관성(간호학/사회복지학 등)은 재확인됨. 신규로 동일 "Robo Tech Valley"(방글라데시 Dhaka) 연구실이 2026-01에 간호/의료AI/IoT/농업 등 로봇공학과 전혀 무관한 논문 6편(arXiv 2601.17414, 2601.08240, 2601.20366, 2601.08484, 2601.21595, 2601.15830)을 대량 게재한 정황을 arXiv HTML 원문 직접 대조로 확인함. 논문공장(paper mill)/AI-slop 의심이 강화되었으나 공식 조사·철회 기록은 없어 "단정" 서술은 금지. 이 논문의 성능 수치 인용 금지는 계속 유지.
4. **arXiv 2312.04072 "23.97ms" 수치**: 재검증에도 원문·전체 웹에서 근거 미발견. 2026-07-20, 2026-09-14 2회 연속 확인 불가 — **사실상 확정적 인용 금지로 처리 권고**. (해당 논문은 애초에 음성인식/감시가 주제로 장애물 회피 지연시간과 직접 연관성 낮음.)
5. **초음파+APF(인공잠재장) 직접 결합 연구 공백 지속**: 이번 회차에도 명확한 결합 사례 미발견. 후보 3건(arXiv 2504.11064 UAV 편대, Springer 10.1007/978-981-95-8981-4_15, GitHub uu-isrc-robotics/potential_fields_based_obstacle_avoidance)은 초음파 직접 결합 여부를 원문에서 확인하지 못해 **다음 회차 우선 조사 대상으로 이월**.
6. **GitHub Mingrui-Yu/RaspberryCar 상태 갱신**: 최종 커밋 2020-05-24 확인 — "비활성 프로젝트"로 판정 갱신(6년 이상 미유지, 참고용 가치만 있고 최신 기법 대표성 없음).
7. **신규 실무 참고 — ROS2 Nav2 통합**: 공식 문서(navigation.ros.org, docs.nav2.org)에 초음파 데이터를 LaserScan으로 변환해 Nav2에 통합하는 방식이 명시되어 있으며, 저사양 장치(라즈베리파이)에는 2D ObstacleLayer가 권장됨. GitHub 이슈 ros-navigation/navigation2#5718에 통합 관련 실무 난제 보고됨. 단 정량적 벤치마크 수치는 미확인.

**Why:** 격주 리서치 파이프라인(2주 주기)에 따른 후속 갱신 — 이전 회차의 미해결/상충 항목 검증 상태를 최신화하고, 신규 등장한 항공로봇 초음파 연구를 포착하기 위함.
**How to apply:** 
- HC-SR04 다중센서 crosstalk 지연값은 60ms를 기본 채택하되, 순차발사 방식 설계 시에는 33ms(저신뢰, 별도 목적)도 참고 가능함을 구분해서 서술할 것.
- arXiv 2312.04072 "23.97ms"와 LineMaster Pro(2603.13907)의 성능 수치는 계속 인용 금지.
- 초음파+APF 결합 공백은 다음 회차(2026-09-28 예상)에 후보 3건 원문 직접 확인부터 시작할 것.
- Saranga/BatDeck 핵심 수치(1.2mW, -4.9dB, MSE 0.019 m/s, 136m/8분)는 인용 가능(검증됨)하되 "70%+", "17배/50%" 등 파생 요약 수치는 원문 대조 전까지 신중히 사용.
