2026-07-20 초음파 센서 장애물 회피 리서치([[초음파-센서-장애물회피-리서치-2026-07-20]]) 중 발견된 사례를 계기로 정리하는 arXiv 프리프린트 신뢰도 탐지 방법론:

**의심 사례:** arXiv 2603.13907 "LineMaster Pro" (2026-03). 서지사항과 수치 자체는 실재하지만 다음 신호가 동시에 관찰됨:
1. 저자 소속이 논문 주제(로보틱스/센서)와 전혀 무관 (간호학과, 사회복지학과 등).
2. 저자 소속 중 하나가 실제 학술기관이 아니라 방글라데시의 로보틱스 부품 판매 소규모 상점("Robo Tech Valley")을 기관명처럼 표기.
3. ResearchGate에 유사/중복 내용이 별도 게재된 정황.

**Why:** arXiv는 동료심사 없는 프리프린트 서버이므로 AI로 생성된 저품질("AI-slop") 논문이 실제 연구처럼 검색 결과에 노출될 수 있음. source-verifier 단계에서 이를 걸러내지 못하면 최종 보고서에 신뢰 불가능한 수치가 인용될 위험이 있음.
**How to apply:** 향후 리서치에서 arXiv 논문을 인용하기 전 다음을 확인:
   - 저자 소속 목록이 논문 주제와 학문적으로 연관되는지 확인 (예: 로보틱스 논문에 간호학과/사회복지학과 저자가 다수 포함되면 경고 신호).
   - 소속 기관명이 실재 대학/연구소가 아니라 개인 상점/스타트업 이름일 가능성 검색으로 확인.
   - 동일/유사 제목·수치가 ResearchGate 등 비동료심사 플랫폼에도 중복 게재되어 있는지 확인.
   - 위 신호가 2개 이상 동시에 나타나면 해당 논문의 수치를 "미검증/의심"으로 표기하고 최종 보고서 인용에서 배제하거나 명시적으로 경고 표기.
   이 기준은 로보틱스 분야뿐 아니라 다른 주제의 arXiv 프리프린트 검증에도 동일하게 적용 가능.

**재확인 및 확장 (2026-08-03):** 라즈베리파이 OpenCV 차선 인식 리서치([[라즈베리파이-opencv-차선인식-리서치-2026-08-03]])에서 arXiv 2603.13907 "LineMaster Pro"를 독립적으로 재검토한 결과, 저자 소속(간호학과/사회복지학과) 불일치가 다시 확인되어 의심 판정이 강화됨. 추가로 새롭게 드러난 사실: 이 논문의 실제 주제는 "OpenCV 카메라 기반 차선인식"이 아니라 **"적외선(IR) 센서 기반 라인트레이서"**임 — 즉 초음파 리서치(회피 알고리즘 문맥)와 차선인식 리서치(카메라 인식 문맥) 양쪽에서 검색 키워드("라인/차선 추종")에 걸려 재등장할 수 있는 논문임이 확인됨. 향후 "차선 인식", "라인 추종", "라인트레이서" 등 관련 키워드로 리서치를 수행할 때마다 이 논문이 재등장할 가능성이 높으므로 매번 인용 금지 원칙을 재적용할 것.

**재확인 및 강화 (2026-09-14):** 초음파 센서 장애물 회피 격주 후속 리서치([[초음파-센서-장애물회피-리서치-2026-09-14]])에서 동일 "Robo Tech Valley"(방글라데시 Dhaka) 연구실이 2026-01에 간호/의료AI/IoT/농업 등 로봇공학과 전혀 무관한 논문 6편(arXiv 2601.17414, 2601.08240, 2601.20366, 2601.08484, 2601.21595, 2601.15830)을 대량 게재한 정황을 arXiv HTML 원문 직접 대조로 신규 확인 — "동일 그룹의 무관 분야 대량 게재"라는 신호가 신규 패턴으로 추가됨. 단 공식 조사·철회 기록은 없으므로 "논문공장 단정" 서술은 여전히 금지.

**재확인 및 강화 (2026-09-28):** 라즈베리파이 OpenCV 차선 인식 4회차 격주 후속 리서치([[라즈베리파이-opencv-차선인식-리서치-2026-09-28]])에서 LineMaster Pro가 재검색에도 재등장(신규 후속논문·철회 없음)함을 확인. **신규 확인**: ResearchGate에 서로 다른 publication ID 2건(#402481169, #404308606)으로 중복 게재된 구체적 정황을 처음으로 특정 — 위 신호 목록의 3번("ResearchGate 중복 게재")이 이번에 ID 단위로 구체화됨. "Robo Tech Valley"가 실제 로보틱스 부품상점임은 2026-08-03, 2026-09-14에 이어 3번째 세션 독립 재확인. 인용 금지 계속 유지.
