**주제**: 라즈베리파이 기반 OpenCV 차선 인식 최신 기법 (2026-09-28 격주 후속 리서치, 4회차)
**보고서**: outputs/2026-09-28-라즈베리파이-OpenCV-차선인식-최신기법.md
**이전 회차**: [[라즈베리파이-opencv-차선인식-리서치-2026-08-03]]

**이전 리서치와의 관계:** [[라즈베리파이-opencv-차선인식-리서치-2026-08-03]]에서 이월된 미해결 공백 2건(Pi5/Bookworm 호환성, Donkeycar CV 오토파일럿 실전 사례)을 재확인하고, LineMaster Pro([[arxiv-논문공장-탐지-방법론]]) 의심 정황을 재검증하기 위한 4회차 격주 후속 조사. 신규로 경량 딥러닝 Pi 실전검증 후보 프로젝트를 발견함.

핵심 발견:
1. **직전 회차(2026-08-03) 이월 공백 2건 모두 진전 없음**: (a) Pi5/Bookworm 호환성 — uvbakutan, salimandre, emirelesg, jerinpeter 4개 프로젝트 모두 유지보수 중단 상태 재확인, 여전히 미검증. (b) Donkeycar CV 오토파일럿 실전 적용 사례 — 공식 문서 외 발견되지 않음. **원인 진단**: forum.donkeycar.com과 Reddit이 WebSearch에 색인되지 않는 것으로 추정됨 — 다음 회차에 해당 포럼/커뮤니티 직접 탐색 전략 필요.
2. **★신규 발견 — nima-salamat/self-driving-robot** (경량 딥러닝 Pi 실전검증 공백의 유력 후보): 903 커밋·8 stars·MIT 라이선스 확인. PR #11(2026-09-18)에서 unet_depthwise_nano(52,191 파라미터)·unet_depthwise_small(253,919 파라미터, 256×256 입력) NCNN 포맷 경량 UNet 차선검출 모델 추가 확인됨. Pi 카메라 벤치마크 스크립트(`--camera-mode picam`) 존재 확인되나 **실측 fps/정확도 수치는 미게시(미확인 상태 유지, 다음 회차 재추적 필요)**. 커밋 이력 정상성은 최근 37건 샘플 확인 결과 정상(feat/fix/test/docs 컨벤션)이나, 전체 이력·기여자 수는 페이지 로딩 실패로 부분확인에 그침 — **8 stars 대비 903 커밋이라는 이례성은 완전히 해소되지 않음**, 다음 회차 code frequency 그래프 재확인 권고.
3. **FPS 미검증 수치 확산 패턴 신규 확인**: fleetstack.io에서 zbotic.in([[라즈베리파이-opencv-차선인식-리서치-2026-08-03]]에서 인용금지 판정)과 거의 동일한 "Pi5 640×480 30+fps" 주장 발견. WebFetch 2회 모두 EGRESS_BLOCKED로 원문 미확인. fleetstack 자체는 실사 SaaS 기업 도메인(Scamadviser 정상 판정)으로 zbotic.in보다 일반신뢰도는 높으나, 구체 수치의 벤치마크 근거는 확인 불가 — **인용 보류로 신규 추가**(zbotic.in과 동일 처리). 동일한 미검증 FPS 수치가 서로 다른 사이트에서 반복 등장하는 것으로 보아 SEO 재게시/복제 콘텐츠 관행이 이 분야에도 존재할 가능성 시사.
4. **발행일 오탐 패턴의 신규 변종 발견 — 자동봇 커밋**: Ali-Kalsekar/Lane-Detection-and-Driver-Assistance-System 저장소가 "v1.0.0(2024)" 자체 표기이나 GitHub 메타데이터상 2026-09-27 업데이트로 노출되어 "활발한 신규 프로젝트"처럼 보였음. 실제 커밋 확인 결과 대부분 "Auto-update README login stamp"라는 **자동화 봇 커밋**(잔디 유지용 추정)이었고 실질 기능 수정은 1건뿐. → **방법론 교훈**: "GitHub 최근 업데이트일"도 자동봇 커밋으로 오도될 수 있으므로 커밋 메시지 내용까지 확인 필요. 기존 [[리서치-발행일-검증-방법론]]의 "사이트가 오래된 콘텐츠를 최신처럼 노출" 패턴과 다른, "저장소 활동 지표 자체가 봇으로 부풀려지는" 새로운 변종.
5. **신규 학술자료 3건 검증**: arXiv 2604.22872(Central Michigan Univ., 정상, 레드플래그 없음), arXiv 2506.15870(UCF, 정상, 단 2025-06-18 제출이므로 "신규"는 아님) 모두 논문공장 신호 없이 정상 확인됨. arXiv 2409.03114는 논문 자체는 정상이나 **원 수집 시 소속을 "미네소타대"로 오인 — 실제로는 Lawrence Technological University(+Michigan State Univ. 공동)임을 정정 확인**. **방법론 교훈**: 저자 소속은 검색 스니펫만으로 단정하지 말고 교수 프로필 등 1차 출처로 재확인할 것.
6. **arXiv 2603.13907 "LineMaster Pro" 재확인 — 의심 신호 추가 강화**: 이번 회차 재검색에서도 재등장(신규 후속논문 없음, 철회 없음). **신규 확인**: ResearchGate에 서로 다른 publication ID 2건(#402481169, #404308606)으로 중복 게재된 정황 발견 — 전형적 논문공장 신호 추가([[arxiv-논문공장-탐지-방법론]] 신호 목록에 부합). "Robo Tech Valley"가 학술기관이 아닌 방글라데시 다카 소재 실제 로보틱스 부품상점임을 직접 재확인(2026-08-03/2026-09-14에 이어 3번째 세션 재확인). 인용금지 유지.
7. **방법론 관찰**: WebFetch 차단이 이번 회차엔 EGRESS_BLOCKED 형태로 재현(arxiv.org, fleetstack.io) — 직전 회차([[webfetch-403-접근제한-관찰]]) 403과 다른 에러 유형이나 결과적으로 원문 직접 대조 불가라는 점은 동일. 반대로 github.com은 이번 회차 정상 동작(403 미재현) — **도메인별로 차단 패턴이 유동적임을 시사**. api.github.com(GitHub API)은 이번엔 403으로 신규 차단됨 — GitHub 웹페이지 직접 렌더링으로 우회하여 대응함.

**Why:** RC카 프로젝트의 시각 인식(차선 인식) 구현 방식을 결정하기 위한 4회차 격주 정기 리서치. 직전 회차 이월 공백 해소 및 신규 동향 포착.
**How to apply:**
- Pi5/Bookworm 호환성과 Donkeycar CV 오토파일럿 실전 사례는 3회 연속(2026-08-03, 2026-09-28 집계상 사실상 지속) 미해결 — 다음 회차에는 forum.donkeycar.com/Reddit 직접 탐색 등 WebSearch 색인 한계를 우회하는 별도 전략을 반드시 적용할 것.
- nima-salamat/self-driving-robot의 경량 UNet 모델은 "실전검증"으로 인용하기 전에 실측 fps/정확도 수치 게시 여부를 반드시 재확인할 것(현재는 미확인).
- fleetstack.io의 "Pi5 30+fps" 수치는 zbotic.in과 동일하게 인용 보류 처리하고, 벤치마크 근거 없는 동일 수치가 여러 사이트에서 반복되면 우선적으로 복제/SEO 콘텐츠를 의심할 것.
- GitHub 저장소의 "최근 업데이트" 지표만으로 활발한 프로젝트라고 판단하지 말고, 커밋 메시지를 확인해 자동봇 커밋 여부를 구분할 것.
- arXiv 논문 저자 소속은 스니펫이 아닌 1차 출처(교수 프로필, 대학 홈페이지)로 재확인할 것.
- arXiv 2603.13907은 계속 인용 금지 유지, ResearchGate 중복게재 신규 근거를 [[arxiv-논문공장-탐지-방법론]]에 반영할 것.
