**주제**: 초음파 센서 기반 장애물 회피 알고리즘 동향 (2026-11-09 격주 후속 리서치, 3회차)
**보고서**: outputs/2026-11-09-초음파-센서-장애물-회피-알고리즘-동향.md
**이전 회차**: [[초음파-센서-장애물회피-리서치-2026-09-14]], [[초음파-센서-장애물회피-리서치-2026-07-20]]

**이전 리서치와의 관계:** 2회차([[초음파-센서-장애물회피-리서치-2026-09-14]])에서 다음 회차 최우선 과제로 이월된 "초음파+APF 직접결합 연구 공백" 후보 3건(arXiv 2504.11064, Springer 10.1007/978-981-95-8981-4_15, GitHub uu-isrc-robotics/potential_fields_based_obstacle_avoidance)을 원문 직접 확인하는 것이 3회차의 핵심 목표였음.

핵심 발견:
1. **초음파+APF 직접결합 공백 — 부분 해소되었으나 학술적으로는 여전히 공백**:
   - os.mbed.com "Potential Field Robot"(Cyntal, mbed NXP LPC1768): HC-SR04 sonar 2개를 motor velocity의 virtual force로 직접 변환 — 초음파+APF 직접결합을 실제로 보여주는 **최초의 구체적 사례**로 확인됨. 단 비peer-review 개인 취미 프로젝트, 날짜 미확인(2010년대 추정, 구형 플랫폼), mbed.org 저장소는 2026-07 영구삭제 예정 공지 있음 → **신뢰도 낮음**으로 분류, 다음 회차 아카이브 확보 시급.
   - arXiv 2504.11064 "DSA-AAPF"(UAV 포메이션, MDPI *Drones* 9(6):390, DOI 10.3390/drones9060390 게재): MATLAB 시뮬레이션만, ultrasonic/sonar 언급 없음(부분확인, 2차소스 기반) → 초음파 비결합 재확인.
   - GitHub uu-isrc-robotics/potential_fields_based_obstacle_avoidance: 소스코드 직접열람 확인 — LaserScan(라이다) 기반, docstring엔 "laser and/or sonar" 언급이 있으나 실제 sonar 처리 코드는 없음 → 초음파 비결합 재확인.
   - **종합 판단**: "학술적으로 검증된(peer-reviewed) 초음파+APF 직접결합 연구"는 3회차까지도 공백 상태. "실무/취미 수준 결합 사례는 존재(os.mbed.com)하나 학술 검증 사례는 없음"으로 판정이 한 단계 구체화됨. 4회차 이후 탐색 범위를 초음파+VFH, 초음파+DWA 등 유사 기법으로 확장할지 판단 필요.

2. **DOI 혼동 이슈 — 유사 논문으로 대체 발견, 원 DOI는 여전히 미확인**: 1~2회차가 찾던 Springer DOI `10.1007/978-981-95-8981-4_15`는 3회차에도 확인불가(doi.org/link.springer.com 접근차단 + 다각도 검색 매칭 없음). 대신 유사 주제의 실존 논문 **DOI `10.1007/978-3-032-12999-4_50`**(Jongchanachavawat 외, "A Low-Cost Obstacle Avoidance System Prototype for Autonomous Wheelchairs Using a Servo-Mounted Ultrasonic Sensor", Springer *Smart Innovation, Systems and Technologies* vol.468, pp.569-579, 2026)을 KMITL dspace + SWU 기관레포지토리 2곳에서 독립 교차확인(제목·venue·성공률수치 100%/80%/60% 모두 일치, 실패원인은 2cm 이내 근접물체 미감지, APF는 미사용, 단순 규칙기반). **원래 DOI(`...8981-4_15`)가 이 논문의 오기였을 가능성**이 제기되었으나 확정되지 않음 — 4회차에서 doi.org 직접 조회로 재확인 필요. 정확한 출판 월/일은 미확인(연도만 확인).

3. **변동 없음 항목**: LineMaster Pro(arXiv 2603.13907) v1 단일본 유지·철회공지 없음·논문공장 의심 판정 유지(인용금지, 2026-07-20→09-14→11-09 3회 연속). arXiv 2312.04072 "23.97ms"도 인용금지 유지(이번 회차는 재검증 생략, 과거 판정 그대로 적용 — 단 생략했다는 사실 자체를 명시).

4. **GitHub `DRL-robot-navigation-IR-SIM` 반증됨**: README 직접열람 결과 "2D laser sensor data" 명시, ultrasonic 아님 — 센서 불명이던 항목이 **초음파 비기반으로 확정**됨. 초음파 기반으로 분류하면 오류이므로 향후 "참고용(범위 외)"로만 취급할 것.

5. **방법론 — WebFetch 차단 범위가 거의 전역으로 확대**: 이번 세션은 **github.com을 제외한 거의 모든 외부 도메인**(arxiv.org, doi.org, link.springer.com, mdpi.com, os.mbed.com, dspace.kmitl.ac.th, api.crossref.org, export.arxiv.org 등)이 **DNS 차단(ENOTFOUND)**됨. 기존 관찰([[webfetch-403-접근제한-관찰]])의 "도메인별·세션별 유동적 차단"이 이번엔 "github.com만 예외, 나머지 거의 전부 차단"이라는 더 극단적인 형태로 재확인됨. 다수 항목이 WebSearch 스니펫(2차정보) 기반으로만 검증되어 신뢰도가 1차 출처 직접열람 대비 낮음. [[webfetch-403-접근제한-관찰]]에 6번째 재확인으로 추가 반영함.
   - 대학 기관 리포지토리(dspace, ir 계열) 2곳 이상 독립교차확인은 WebFetch 직접 접근이 막힌 상황에서도 신뢰도 높은 검증 패턴으로 재확인됨(DOI 10.1007/978-3-032-12999-4_50 케이스).

**Why:** 격주 리서치 파이프라인(2주 주기)에 따른 3회차 후속 갱신 — 2회차에서 이월된 "초음파+APF 결합" 후보 3건을 원문 확인하고, DOI 혼동·LineMaster Pro·23.97ms 등 상충/미해결 항목의 최신 상태를 점검하기 위함.
**How to apply:**
- "초음파+APF 직접결합"을 보고서에 서술할 때는 "학술 검증 사례 없음(공백), 단 비peer-review 취미 프로젝트(os.mbed.com) 1건은 존재"로 구분해서 표기할 것. os.mbed.com 사례를 학술적 근거로 오인 인용하지 않도록 주의.
- DOI `978-3-032-12999-4_50`은 인용 가능(2기관 독립교차확인, 신뢰도 높음). DOI `978-981-95-8981-4_15`는 3회 연속 확인불가이므로 사실상 폐기하거나 오기로 간주하고 재언급을 최소화할 것(단 완전 확정 전까지 "오기로 추정"이라는 표현 유지).
- GitHub `DRL-robot-navigation-IR-SIM`은 초음파 기반으로 인용하지 말 것(반증 확정).
- 다음(4회차, 격주 후) 리서치 우선 조사 대상: (1) DOI 혼동 재확인(doi.org 접근 확보 시), (2) os.mbed.com 프로젝트 날짜 확인 및 아카이브 확보(2026-07 영구삭제 예정 공지 대응 시급), (3) WebFetch 접근 가능해지면 arXiv 2504.11064 원문 직접 재확인(현재는 2차 소스 기반 부분확인에 불과).
- 매 회차 시작 시 주요 도메인(arxiv.org, doi.org, link.springer.com, mdpi.com 등) 접근성을 선제 점검하는 절차를 강화할 것.
