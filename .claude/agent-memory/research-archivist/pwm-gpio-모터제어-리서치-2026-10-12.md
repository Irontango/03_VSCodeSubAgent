**주제**: RC카 PWM/GPIO 모터 제어 오픈소스 프로젝트 동향 (2026-10-12 격주 후속, 2026-08-17 1회차 이후 첫 후속)
**보고서**: outputs/2026-10-12-RC카-PWM-GPIO-모터제어-오픈소스-동향.md
**이전 리서치와의 관계**: [[pwm-gpio-모터제어-리서치-2026-08-17]]의 첫 후속 회차. 약 8주 경과.

핵심 발견:

1. **RpiMotorLib — 변화 없음(정체 지속).** 최종 커밋 **2026-05-11**로 1회차와 동일, 5개월째 신규 커밋 없음. 3rd-party 애그리게이터 gittrend.io(2026-03-29 표기)와 ecosyste.ms(2024-03-28 표기)는 서로도 불일치하고 GitHub 1차 소스와도 불일치 — **애그리게이터는 stale 캐시로 재확인됨**(아래 #3 참고).
2. **gpiozero — 안정, 신규 이슈 없음.** PyPI 최신 **2.0.1.post3**(2026-07-27) 이후 8주간 신규 릴리스·Pi5 회귀 이슈 없음. 1회차에서 확정한 Issue #1166 해결은 재확인 불필요 상태 유지.
3. **★미확인 공백 2건 해소.** 1회차에서 "미확인"으로 남겼던 **pigpio-rp5(kshetline)**와 **nick-hunter의 TB6612FNG 프로젝트**가 이번 회차 **GitHub 프로필 직접 열람(WebFetch)**으로 둘 다 실존 확인됨.
   - pigpio-rp5: github.com/kshetline/pigpio-rp5, joan2937/pigpio 포크, "Pi5 호환성 실험" 목적, Unlicense, 스타 0, 최근 업데이트 **2024-06-24로 추정(부분확인**, 날짜 렌더링 미확정 — 이월).
   - nick-hunter: github.com/nick-hunter/Raspberry_Pi_TB6612FNG_Python, 10★, 6 forks. 최근 활동 여부는 미확인(이월).
   - **방법론 교훈**: WebSearch만으로 "찾지 못함" 결론을 내리면 안 되고, GitHub 사용자/레포명이 특정된 경우 프로필을 직접 열람해야 함. "검색 결과 부재 ≠ 실재 부재" 패턴으로 명시. (상세는 [[소스검증-함정-2026-08-17]] 참고)
4. **pigpio Pi5 미지원 — 1차 소스 재확인.** Issue joan2937/pigpio#589(2023-11-07 오픈)가 현재(2026-10-12)도 Open. 메인테이너가 DMA/VideoCore mailbox 의존성으로 포팅 어렵다고 명시 — 구조적 미지원 확정.
5. **PID 제어 루프 — 3회차 연속 공백 + pid_py 수치 정정.** 전용으로 활발히 유지되는 라이브러리 여전히 없음(2026-07-19부터 3회 연속). 발견된 3건(360pibot, pid_py, pi-pid) 모두 비활동. **pid_py(ThunderTecke) 수치 정정**: 기존 캐시 "2023-08 / 4★"가 실제로는 "**2024-05-27 / 13★**"로 과소평가되어 있었음.
6. **★방법론 교훈(애그리게이터 수치 자체의 신뢰도).** #1(RpiMotorLib)과 #5(pid_py) 두 사례 모두에서 3rd-party 애그리게이터/캐시 수치가 실제 GitHub 1차 소스와 불일치함이 확인됨. 기존 "최근 업데이트일만으로 활성 판단 금지"(2026-09-28 교훈)에 더해, **"집계 사이트가 제공하는 날짜·스타 수치 자체도 stale할 수 있으므로 GitHub 1차 소스로 재확인해야 한다"**는 원칙을 추가함.
7. **환경 제약.** api.github.com(REST API)이 이번 세션에서 403 전면 차단 → GitHub HTML 페이지 WebFetch로 우회 성공. gpiozero.readthedocs.io는 DNS 실패(ENOTFOUND) → GitHub raw changelog.rst로 대체. PyPI JSON API는 정상. ([[webfetch-403-접근제한-관찰]]의 "차단 패턴 유동성" 관찰과 일치)
8. **이월 공백(다음 회차, 2026-10-26 예정)**: (a) pigpio-rp5의 2024-06-24 이후 최신 활동 여부, (b) PID 제어 루프 전용 활발 라이브러리(4회차째 — 검색 플랫폼 전환 검토: Hackster.io/Instructables/ROS 생태계), (c) nick-hunter TB6612FNG 최근 활동(최종 커밋일 등).

**Why:** RC카 모터 제어 계층의 격주 모니터링 1회차 후속으로, "변화 없음"도 가치 있는 결과(안정성 확인)이며, 1회차 미확인 공백 2건이 해소되고 애그리게이터 신뢰도 문제가 반복 재확인된 것이 이번 회차의 핵심 가치.
**How to apply:** (1) RpiMotorLib/gpiozero/pigpio 관련 질문에는 이번 회차 결론(변화 없음)을 그대로 재사용 가능 — 다음 회차(2026-10-26)까지는 재조사 불필요. (2) GitHub 사용자/레포명이 특정됐지만 WebSearch로 안 나오면 반드시 GitHub 프로필 직접 열람(WebFetch)을 시도할 것. (3) 애그리게이터(gittrend.io, ecosyste.ms 등) 수치는 참고만 하고 GitHub 1차 소스로 반드시 재확인할 것 — 날짜뿐 아니라 스타 수 등 모든 수치가 대상. (4) PID 제어 루프는 다음 회차에 검색 플랫폼을 Hackster.io/Instructables/ROS로 전환 검토.
