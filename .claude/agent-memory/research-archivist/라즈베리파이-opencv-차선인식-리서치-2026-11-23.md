**이전 리서치와의 관계:** [[라즈베리파이-opencv-차선인식-리서치-2026-09-28]]에서 이월된 4대 공백(Pi5/Bookworm 호환성, Donkeycar 실전 CV 사례, nima-salamat 실측치, 미검증 FPS 수치 확산)을 재확인하고, 2026년 하반기 신규 학술자료를 추가 탐색한 5회차 격주 후속 조사.

핵심 발견:
1. **이월 공백 4건 중 완전 해소 0건, 전부 부분해소/미해소 수준에서 종결**:
   - (a) Pi5/Bookworm 호환성 — **★신규** vlmarkov/self-driving-car 발견. README에 "Raspberry Pi 5 board" 명시·최근 실질 커밋 다수(자동봇 아님) 확인되나 **OS가 Ubuntu 24.04이며 Bookworm이 아님** → "부분 해소"에 그침, 순수 Bookworm 공식 사례는 5회 연속에 가깝게 공백.
   - (b) Donkeycar 실전 CV 사례 — forum.donkeycar.com/docs.donkeycar.com 완전 차단 지속(5회 연속). 단 GitHub 공식 이슈트래커(#97/#158/#1085/#1056) 직접 열람으로 **"2026년 신규 CV 관련 이슈 없음"을 소극적으로 확인** — 완전한 공백 해소는 아니지만 "확인 시도 자체가 불가능"에서 "포럼은 막혀도 공식 이슈트래커로 음성 확인 가능"으로 한 단계 진전.
   - (c) nima-salamat/self-driving-robot 실측 fps/정확도 — 여전히 미게시(2회 연속 공백). 단 최근 활동(2026-11-02, 10커밋)이 **CARLA 시뮬레이터 작업으로 전환**되어 실물 Pi 하드웨어 작업과는 무관해짐이 새로 확인됨. 동시에 `--city-lane-detector blsf-beta`라는 신규 실험적 고전 CV 파이프라인(weighted grayscale→median-local thresholding→LSD→binary line-segment filtering→열투영→sliding window→quadratic RANSAC)이 추가됨 — 저장소 자체가 "controlled evaluation 전 기본 검출기로 쓰지 말 것"이라 명시.
   - (d) 미검증 FPS 수치 확산 — zbotic.in 신규 근거 없음(유지), fleetstack.io는 이번 검색에 재노출 안 됨. **source-verifier 추가 확인**: fleetstack.io 자체의 사이트 정체성(GPS 플릿관리/차량관리 SaaS 등 혼재)이 불명확함이 신규로 드러남 — 인용 보류 판정은 유지하되 "사이트 신뢰도 자체도 불명확"이라는 새로운 근거가 추가됨.
2. **★MDPI Electronics 15(2),351 "BLSF" 논문 발견** — nima-salamat의 blsf-beta와 파이프라인 명칭(BLSF)·단계가 상당히 유사하나, **저장소에 해당 논문 인용/링크가 전혀 없어 인용관계는 불명**(독립 구현 가능성 배제 못함, 확정적 연관 주장 금지). 논문 자체의 핵심 주장("2GHz ARM CPU 전용 플랫폼에서 실시간 유지")은 preprint 맥락상 확인되나, **"2GHz"가 특정 라즈베리파이 모델 표준 클럭과 불일치**(Pi4 표준 1.5GHz, Pi5 표준 2.4GHz — 2GHz는 Pi4 오버클럭 수치로만 존재) → "라즈베리파이 특정 모델 매칭"은 미확인(반증 쪽에 가까움). F1 6~7%p 개선 수치는 2025-12 preprint 기준만 확인, 2026-01 MDPI 출판본 동일 유지 여부는 미확인. **저자소속 불일치 신규 발견**: preprint 표기(Chang Jung Christian University) vs 검색된 MDPI 페이지 표기(National Cheng Kung University) — 버전차이/정정 가능성, 미확정.
3. **★arXiv 2601.01696(CDO, 정확도 0.01~1.5% 개선) — "저전력 임베디드=Pi" 일반화가 사실상 반증됨**: 수치 자체는 5개 독립 2차 소스(emergentmind, themoonlight, fugumt, catalyzex, deeppaper)에서 일치 확인되었으나, **"Raspberry Pi"를 명시적으로 언급하는 소스는 5개 중 단 하나도 없음**. "저전력 임베디드 = 라즈베리파이 포함"이라는 암묵적 가정은 근거가 전혀 없고, 0.01~1.5%는 요약 전반에서 "미미한 수치"로 서술됨 — 단순 "미확인"이 아니라 **적극적 반증에 가까운 사례**로 기록할 가치가 있음(기존 "2회 연속 근거 미발견 시 인용금지 격상" 패턴과는 다른, "다수 독립 소스의 동시 침묵"이 반증 신호가 되는 신규 변종).
4. **arXiv 2604.02188 "TuSimple 모델2 93.40%" 수치 — 출처 불명 확정**: web-researcher가 제시한 수치를 source-verifier가 독립 2차 검색 2회(alphaxiv.org 미러 포함) 모두에서 확인하지 못함. 단순 미확인이 아니라 **근거 자체가 어디에도 존재하지 않는 "출처 불명" 수준**으로 처리하며, 향후 재인용 시 "출처 불명" 표기 필수.
5. **arXiv 2604.22872 "Pi-AV"** — "Pi-based Autonomous Vehicle Testbed"로서 실제 라즈베리파이 기반 플랫폼임은 2차 미러(alphaxiv.org)로 부분확인되나, **구체 fps/정확도 수치는 검색으로 확인 안 됨**. 직전 회차(2026-09-28)엔 "확인됨"으로 분류했었는데, 이번 회차 재검증 결과 Pi 실측치 미확인 부분이 새로 드러나 등급을 **"부분확인"으로 하향 유지**함 — 격주 후속에서 과거 "확인됨" 판정이 재검증으로 하향될 수 있음을 보여주는 사례.
6. **인용 금지/저신뢰 목록 변동 없음**: arXiv 2603.13907 "LineMaster Pro" — 이번 세션도 재검색에서 해당 ID/제목 논문을 전혀 찾지 못함(존재 자체 재현 불가), 신규 신호(철회/정정) 없이 인용금지 유지. zbotic.in·fleetstack.io "Pi5 30+fps"도 인용 보류 유지.
7. **방법론 관찰 — WebFetch 차단 유형 재차 상이**: 이번 세션 차단 도메인은 zbotic.in, arxiv.org, www.mdpi.com, forum.donkeycar.com, docs.donkeycar.com이며 에러 유형은 **ENOTFOUND(DNS)**. 직전 회차(2026-09-28)는 EGRESS_BLOCKED 유형이었음 — 동일 주제 리서치에서도 회차마다 에러 유형 자체가 바뀌는 패턴이 재확인됨([[webfetch-403-접근제한-관찰]] 참고). 반대로 github.com/api.github.com은 이번 회차 정상 동작.

**Why:** RC카 프로젝트의 시각 인식(차선 인식) 구현 방식을 결정하기 위한 5회차 격주 정기 리서치. 이월 공백 재검증 및 2026년 하반기 신규 학술자료 확보.
**How to apply:**
- Pi5/Bookworm 공식 호환 사례는 5회 연속 공백 — vlmarkov가 가장 근접하나 OS 불일치로 완전 해소 아님, 다음 회차에도 "Bookworm 명시 + Pi5" 조건을 둘 다 만족하는 사례를 우선 탐색할 것.
- Donkeycar 공식 포럼이 계속 막혀도 GitHub 공식 이슈트래커 직접 열람으로 "신규 활동 없음"을 소극적으로 확인하는 우회 경로가 유효함을 확인했으므로 표준 절차로 유지할 것.
- nima-salamat 저장소는 CARLA 시뮬레이터 전환으로 실물 Pi 벤치마크 확보 가능성이 낮아지고 있음 — 다음 회차엔 "실물 Pi 복귀 여부"를 우선 확인하고, blsf-beta와 MDPI BLSF 논문의 인용관계는 저장소 업데이트나 Google Scholar 인용 네트워크로 재확인할 것.
- MDPI BLSF 논문의 "2GHz ARM CPU" 수치는 특정 Pi 모델과 매칭하지 말고 범용 ARM SBC/오버클럭 조건으로만 서술할 것. preprint-대-출판본 수치 차이 및 저자소속 불일치는 원문 직접 대조 전까지 미확정으로 유지.
- arXiv 2601.01696의 "저전력 임베디드=Pi" 가정은 5개 독립 소스 동시 침묵을 근거로 사실상 반증으로 취급하고, 향후 유사 일반화 주장은 "다수 독립 소스가 동시에 언급하지 않는 경우 반증 신호로 간주"하는 원칙을 적용할 것.
- arXiv 2604.02188 "93.40%" 수치는 출처 불명으로 재인용 금지(표기 시 반드시 "출처 불명" 명시).
- arXiv 2604.22872는 Pi 플랫폼 자체는 부분확인이나 실측치는 미확인 상태로, 과거 "확인됨" 분류를 과신하지 말고 매 회차 재검증할 것.
