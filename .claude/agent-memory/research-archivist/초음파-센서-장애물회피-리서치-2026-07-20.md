**주제**: 초음파 센서 기반 장애물 회피 알고리즘 동향 (2026-07-20 리서치)
**보고서**: outputs/2026-07-20-초음파-센서-장애물-회피-알고리즘-동향.md

**이전 리서치와의 관계:** [[rc카-자율주행-리서치-2026-07-19]]에서 초음파 센서는 "긴급정지 보조" 수준으로만 다뤄졌음. 이번 리서치는 이를 확장하여 다중센서 배열, 퍼지로직, 인공 잠재장(APF), 센서융합, crosstalk 처리, 폴링-제어루프 통합 등 "회피 알고리즘 자체"를 조사함.

핵심 발견:
1. 검증된 핵심 자료
   - MDPI Sensors 21(20):6777 (Zhao et al., 2021-10-12) — 다중센서 융합 기반 회피, 검증됨.
   - MDPI Robotics 11(6):130 (Type-2 Fuzzy Logic, 2022-11-16) — 검증됨.
2. HC-SR04 다중센서 crosstalk 방지 표준 지연시간은 **60ms** (SparkFun/HandsOnTec 공식 데이터시트 기준). "33ms"는 신뢰도 낮은 단일 SEO 블로그의 자체 계산치이므로 인용 시 사용 금지.
3. **경고 — arXiv 2603.13907 "LineMaster Pro" (2026-03)**: 서지사항/수치 자체는 실재하나 저자 소속이 주제와 전혀 무관(간호학과, 사회복지학과, 방글라데시 로보틱스 부품판매 상점 "Robo Tech Valley")하고 ResearchGate 중복 게재 정황 있음 — arXiv "AI-slop"(AI 생성 저품질 프리프린트) 논문공장 패턴으로 의심됨. 상세 탐지 기준은 [[arxiv-논문공장-탐지-방법론]] 참고.
4. arXiv 2312.04072의 "23.97ms 종단간 지연" 수치는 확인 불가/환각 의심으로 최종 보고서에서 배제함. 향후 이 논문 재인용 시 해당 수치 사용 금지.
5. **미해결 공백(gap)**: 초음파 센서 + 인공 잠재장(APF) 기법을 직접 결합한 2023~2026년 최신 연구/구현체 미발견. 최신 APF 연구는 대부분 라이다/카메라 기반. 이 공백을 메울 자료 발견 시 우선 조사 대상으로 표시.
6. 실무 참고용 오픈소스: GitHub `Mingrui-Yu/RaspberryCar` (초음파+IR+카메라 통합, 라즈베리파이). 게시일 미확인이나 실무 참고 가치 높음.
7. 방법론 재확인: automaticaddison.com 등 커뮤니티/블로그가 검색 결과에서 최신처럼 노출되나 실제로는 오래된 자료(이번 사례 2019년)인 경우가 재차 확인됨 — [[리서치-발행일-검증-방법론]]의 유효성 재입증.

**Why:** RC카 프로젝트의 초음파 센서 활용을 "긴급정지"를 넘어 실제 "회피 알고리즘" 설계 수준으로 고도화하기 위한 후속 리서치.
**How to apply:** 장애물 회피 알고리즘 설계/구현 논의 시 다중센서 crosstalk 방지에는 60ms 지연을 기준값으로 사용. APF+초음파 결합 논문/구현체가 새로 검색되면 이 공백이 해소된 것으로 갱신. arXiv 2603.13907과 2312.04072의 특정 수치는 재검증 없이 인용하지 말 것.
